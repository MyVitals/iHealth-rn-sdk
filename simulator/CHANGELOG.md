## 什么时候要出新版本

- SDK 改了协议层（认证、帧格式、新指令）→ 固件必须跟着改，否则模拟板和新 SDK 对不上。
- 新机型接入 SDK → 固件加 `ih_<model>.c`，manifest 里 models 多一项。
- 只是 App 侧改动 → 固件不用动。

## 固件里的"设备固件版本"不是这个版本号

`scenario fw_old` / `fw_new` / 串口 `fw <fff> <hhh>` 改的是**模拟出来的那台设备**上报的固件 / 硬件版本（180A 和 0x24 里的字段），
用来测 App 对不同设备固件版本的处理；和本表的模拟固件版本是两回事。
